# CampusLife - COMPX202/Y05853 Assignment One

First Android application for COMPX202 (University of Waikato). CampusLife is a pocket
guide to the university with four topics: **Facilities**, **Events**, **Clubs** and
**Support**.

## How each part of the brief is implemented

| Part | Requirement | Where |

| B | Responsive layout reproducing Figure 1: campus banner with a centred white title, four topic cells in a 2x2 grid, no hard-coded sizes except the 40sp banner title | `app/src/main/res/layout/activity_main.xml`, `res/values/dimens.xml` |
| C | App renamed CampusLife, logo used as the launcher icon, `green` `#1B5E20` and `light_green` `#66BB6A` added, button selector (green idle / light green pressed) | `res/values/strings.xml`, `res/values/colors.xml`, `res/drawable/button_selector.xml`, `res/mipmap-anydpi-v26/*` |

| H | `DetailActivity.onCreate()` populates the screen from `arrays.xml` (titles, content, image names) without any `if` or `switch` | `res/values/arrays.xml`, `DetailActivity.java` |
| I | Clear structure and helpful comments | throughout |

### How the unique identifier works

The four buttons are declared in `MainActivity` in the same order as the entries in
`arrays.xml`, so the position of the button in that array double as the topic identifier.
`MainActivity` passes that index, plus the short topic name used by the header, and
`DetailActivity` reads `titles[index]`, `contents[index]` and `imageNames[index]` directly.
That is why no `if` statement or `switch` block is needed anywhere in the app.

### Responsive behaviour

* All padding, text sizes and icon sizes live in `res/values/dimens.xml`; the only literal
  size in the layouts is the 40sp banner title allowed by the brief.
* The banner and the topic grid use `layout_weight`, so they fill any screen size.
* Portrait uses `res/layout/activity_main.xml` (2x2 grid); landscape automatically picks
  up `res/layout-land/activity_main.xml` (one row of four).

## Building

Open the project in Android Studio (Giraffe or newer) and run the `app` configuration, or
from a command line with a JDK 17 and the Android SDK installed:

```
./gradlew assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`. `local.properties`
is generated by Android Studio and is deliberately not committed.
